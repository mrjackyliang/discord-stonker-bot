Delete messages that contain affiliate or tracking links, alert moderators, and ask the author to post a clean link.

## Why Use This Feature?

1. Removes referral and tracking links in every channel, so members can't earn commissions from your community.
2. Names every matched platform in one alert, so moderators see what was removed.
3. Tells the author privately how to repost, so a useful link can come back without the tracking.

## How It Works

- **What it reads** — New messages and edits that change a message's text, from members other than bots, that a regex rule hasn't already deleted. The bot sees edits only for messages it has seen since its last reconnect, up to the 200 most recent in each channel.
- **How it matches** — Every platform pattern runs against the message text as written, and the bot collects every platform that matches.
- **What it does** — When at least one platform matches, the bot posts the alert, sends the direct message, and then makes one attempt to delete the message.

The alert is an embed titled "Affiliate content removed" that shows the author, the channel ID, the matched platforms, an excerpt of up to 700 characters, and a link to the message. It posts before the delete, so it appears even when the delete fails.

:::warning
The panel labels the `channel` setting **Monitored channel**, but the feature checks every channel. That setting is only the <Terminology title="Channel where a feature posts moderator alerts" to="/docs/reference/terminology#alert-channel">alert channel</Terminology>, and leaving it out skips the alert.
:::

## Requirements

- **<Terminology title="Privileged intent that lets the bot read message text" to="/docs/reference/terminology#message-content-intent">Message Content intent</Terminology>** — Switch on this <Terminology title="Intent you switch on in the Developer Portal" to="/docs/reference/terminology#privileged-intent">privileged intent</Terminology> for your application in the Discord Developer Portal.
- **Channel permissions** — The bot needs View Channel and Manage Messages in every channel, and Send Messages and Embed Links in the <Terminology title="Channel where a feature posts moderator alerts" to="/docs/reference/terminology#alert-channel">alert channel</Terminology>.

## Settings

| Field                                                                                                                                               | Description                                                                                                                                                                 |
|-----------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Link patterns (`platforms`)                                                                                                                         | 1 to 100 platforms, each with a **Platform** name of up to 100 characters and a **Regular expression**.                                                                     |
| Monitored channel (`channel`)                                                                                                                       | Optional <Terminology title="Channel where a feature posts moderator alerts" to="/docs/reference/terminology#alert-channel">alert channel</Terminology> for removal alerts. |
| Member notice → Text (`direct-message-payload.content`)                                                                                             | Optional direct message of up to 2,000 characters, sent as written without filling in message variables.                                                                    |
| <Terminology title="Roles whose members a rule skips" to="/docs/reference/terminology#excluded-roles">Exempt roles</Terminology> (`excluded-roles`) | Optional list of 1 to 100 roles whose members the feature skips.                                                                                                            |

## Example

```json title="Affiliate cleanup settings"
{
  "platforms": [
    { "platform": "Amazon", "regex": { "pattern": "[?&]tag=", "flags": "i" } }
  ],
  "channel": { "channel-id": "123456789012345678" },
  "direct-message-payload": { "content": "Please repost the link without the affiliate tag." }
}
```

## Limits

- **Platforms** — Up to 100.
- **Excerpt** — Up to 700 characters of the message.

## Troubleshooting

- **The alert says "removed" but the message is still there** — The bot lacks Manage Messages in that channel.
- **A member got two direct messages** — A regex rule matched but couldn't delete the message, so affiliate cleanup ran too.
- **Moderators' links are removed** — Administrators aren't skipped automatically, so add their roles to **<Terminology title="Roles whose members a rule skips" to="/docs/reference/terminology#excluded-roles">Exempt roles</Terminology>**.

:::info[Changes from the legacy bot]
The <Terminology title="The original config.json bot this rewrite replaces" to="/docs/reference/terminology#legacy-bot">legacy bot</Terminology> skipped anyone with the Administrator permission, and it sent the alert, the direct message, and the delete at the same time. The rewrite skips only <Terminology title="Roles whose members a rule skips" to="/docs/reference/terminology#excluded-roles">excluded roles</Terminology> and runs those steps in order.
:::
